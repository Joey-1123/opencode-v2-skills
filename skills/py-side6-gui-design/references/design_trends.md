# Desktop UI Design Trends (2024-2025)

## Key Trends
1. **Dark Mode Default** — Most professional tools ship dark mode first
2. **Compact Toolbars** — Minimal transport controls, maximize content space
3. **Smooth Animations** — 200-300ms transitions for all state changes
4. **Collapsible Sidebars** — Hamburger menu or toggle for navigation
5. **Split Views** — Resizable panels for data + detail
6. **Real-time Preview** — Live updates as you type/adjust

## Qt-Specific Trends
1. **QSS Theming** — Centralized stylesheets with CSS-like syntax
2. **QGraphicsView** — Hardware-accelerated custom displays
3. **QAbstractItemModel** — Efficient large data sets
4. **QSplitter** — User-resizable panels (persist via QSettings)
5. **QAction Shortcuts** — Global shortcuts with QShortcut or QAction
