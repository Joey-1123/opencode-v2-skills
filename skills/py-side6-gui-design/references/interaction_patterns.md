# Desktop Interaction Patterns

## Navigation
- **Sidebar**: Vertical list of sections (200-250px wide)
- **Tabs**: Horizontal categories in main content area
- **Breadcrumbs**: Path-based navigation for hierarchical data
- **Toolbar**: Icon-based quick actions

## Data Interaction
- **Click**: Select single item
- **Ctrl+Click**: Multi-select
- **Double-click**: Open/activate item
- **Drag & Drop**: Reorder or move items
- **Right-click**: Context menu

## Keyboard Shortcuts
| Key | Action | Context |
|-----|--------|---------|
| Ctrl+S | Save | All views |
| Ctrl+O | Open | File operations |
| Ctrl+N | New | Create new item |
| Ctrl+F | Find | Search/Filter |
| Ctrl+Q | Quit | Application |
| Esc | Cancel | Dialogs, selections |
| Space | Select/Play | Media, lists |
| Ctrl+A | Select All | Lists, tables |
| Ctrl+C/V/X | Copy/Paste/Cut | Editable areas |
| F1 | Help | Application |

## Form Patterns
- Real-time validation (inline, not after submit)
- Clear error messages near the field
- Required fields marked with asterisk
- Auto-save or explicit Save button
- Reset to defaults option
